## 本次更新

此更新带来更流畅、更稳定的输入体验，建议所有用户安装。

- 提升长时使用后的响应速度和内存表现。
- 改进长篇内容末尾的连续输入，保持稳定响应。
- 优化个人词频学习数据的保存，减少学习记录较多时的偶发卡顿。
- 提升与 KOReader MultiUser 的兼容性，避免插件重复加载。
- 保留现有输入方案、候选偏好和个人学习数据，升级后无需重新设置。

## 升级提示

请退出 KOReader，并用新压缩包中的整个 `pinyinime.koplugin/` 替换旧目录，不要合并零散文件。个人设置和学习数据保存在 `koreader/settings/chinesepinyin.lua`，正常覆盖插件目录不会删除它们。

安装完成后，请在 `设置 → 设备 → 键盘 → 拼音输入法` 核对版本 `v1.1.1`，并打开“运行状态与诊断”确认实际词库模式。

## 兼容性

- v2025.10、v2026.03 与 v2026.07 已通过正式验证。
- 更高 KOReader 版本通过运行时能力检测后启用增强层。
- 长文本快速路径覆盖普通 LTR 末尾输入；文本中间、RTL/双向文本或几何不能等价时自动回退到原完整排版路径。
- 插件只接管 KOReader 简体中文虚拟键盘；其他键盘布局不受影响。

## 性能验证

在同一 macOS arm64 KOReader debug emulator 的隔离进程中：

- 10k 字符文本框的预编辑 P95 从 1.411 ms 降至 0.161 ms。
- 200 次真实输入框创建/关闭后，引擎、任务、窗口与弱引用计数全部回零，中位保留 Lua heap 增量为 381.2 KiB。
- 5000 个学习编码触发落盘时，按键 P95/P99/max 为 0.010/0.028/0.115 ms，且同时最多一个 writer。
- 100,000 键 soak 的最大单键延迟为 1.310 ms，SQLite 查询增量为 0，缓存和任务数保持有界。

以上数据用于本地回归门禁，不是 Oasis 1/2 真机 CPU、内存或电子墨水延迟结论。Oasis 1/2 的视口、无触摸与 flash-refresh 模拟仅用于布局和增长趋势验证。
