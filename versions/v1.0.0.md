## 首个正式版本

v1.0.0 将 KOReader 内置简体中文输入法的增强能力整理为可独立安装的插件，并提供完整的中文设置与诊断入口。

主要内容：

- 沿用 KOReader 简体中文键盘、输入框和按键交互；
- 提供紧凑候选栏和可分页的展开候选面板；
- 使用完整万象词库，以及按需查询的学术与通用补充词库；
- 支持全拼、搜狗双拼、拼音加加双拼、微软双拼、小鹤双拼和常用双拼；
- 支持简拼、安全范围内的拼写纠错和整句解码；
- 支持可独立控制的个性化学习与后续词联想；
- 提供自动回退的兼容词库模式；
- 增加中文“运行状态与诊断”、个性化数据清除和版本显示；
- 对候选更新、按键反馈和展开面板进行电纸书刷新适配。

## 升级提示

这是首个公开版本。以后从旧版本升级时，请退出 KOReader，并用新压缩包中的整个 `pinyinime.koplugin/` 替换旧目录，不要合并零散文件。个人设置和学习数据保存在 `koreader/settings/chinesepinyin.lua`，正常覆盖插件目录不会删除它们。

安装完成后，请在 `设置 → 设备 → 键盘 → 拼音输入法` 核对版本，并打开“运行状态与诊断”确认实际词库模式。

## 兼容性

- v2025.10 与 v2026.03 已通过正式验证。
- 更高 KOReader 版本通过运行时能力检测后启用增强层。
- 插件只接管 KOReader 简体中文虚拟键盘；其他键盘布局不受影响。
- 完整数据库无法打开或校验失败时，自动回退到兼容词库。

## 已知边界

- 需要启用 KOReader 简体中文键盘后才会出现输入增强与设置入口。
- 完整词库占用约 151 MiB，设备需要为整个插件预留约 161 MiB；安装和升级时建议至少保留 200 MiB 可用空间。
- 后续词联想以短而可靠的候选为目标，不尝试生成任意长文本。
- 运行时能力检测可降低接口变化风险，但尚未正式验证的 KOReader 新版本仍可能进入安全回退。
