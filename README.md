# 拼音输入法（Pinyin IME）

> 基于 KOReader 内置简体中文输入法的拼音增强插件。

Pinyin IME 沿用 KOReader 的简体中文键盘、输入框与按键交互，在原有输入体验上增加候选栏、完整词库、整句输入、双拼、个性化学习和后续词联想。插件只在简体中文键盘生效，不会替换 KOReader 的其他键盘布局。

**当前版本：v1.1.1**　·　[下载插件](https://github.com/Merpyzf/pinyinime.koplugin/releases/download/v1.1.1/pinyinime.koplugin-v1.1.1.zip)　·　[查看版本说明](https://github.com/Merpyzf/pinyinime.koplugin/releases/tag/v1.1.1)

## 与 KOReader 内置输入法的关系

Pinyin IME 是 KOReader 简体中文输入法的增强层，不是另一套键盘。

- 继续使用 KOReader 自带的简体中文键盘、输入框和按键反馈。
- 在简体中文键盘启用时接管拼音候选与提交；英文和其他语言键盘保持原样。
- 输入方案统一放在插件设置和长按空格的方案选择中，避免与键盘布局菜单重复。
- 插件停用或移除后，相关接管会被完整撤销，KOReader 恢复原有输入行为和菜单。
- KOReader 仍负责插件启用、停用和加载；插件本身不另设启停开关。

## 为离线词库做的优化

完整词库是这个版本的重点。词库查询、候选计算和学习数据处理均在设备本地完成，插件运行没有网络依赖。

### 完整万象词库

主词库来自 Wanxiang 的现代中文词条与权重，经过面向 KOReader 运行环境的构建和索引。发布包内的主数据库约 123 MiB，包含常用词、短语、专名及用于整句解码和上下文排序的数据。

### 学术与通用补充词库

独立的补充数据库约 28 MiB，收录 560,885 条基线缺失记录，覆盖常用表达以及计算机、医学、法律、金融、理工、人文等领域。只有主词库结果不足时才会查询补充库，避免让长尾词条干扰常用候选。

### 适合电纸书设备的查询路径

- 使用只读 SQLite 数据库，运行时不会改写发布词库。
- schema v5 为高频编码、整句上下文和词间转移准备了紧凑查询表。
- 词库首次需要时才初始化，并在多个输入框之间复用，减少不必要的启动成本。
- 查询结果有边界并使用小型缓存，控制内存占用和候选生成时间。
- 候选排序会综合词频、整句路径、输入上下文和可选的个人学习结果。
- 完整数据库无法打开或校验失败时自动回退到兼容词库，普通输入仍可继续。

词库来源、固定版本、生成规则和许可证见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 输入能力

### 全拼与五种双拼

支持全拼，以及搜狗双拼、拼音加加双拼、微软双拼、小鹤双拼和自然码双拼。长按虚拟键盘的空格键，可以在输入时快速切换方案。自然码沿用原“常用双拼”的内部标识和键位，升级后已有方案设置无需迁移。

### 简拼、纠错与整句输入

简拼用于快速召回常用短语；安全范围内的拼写纠错用于处理常见误键；整句解码会组合多段拼音并给出完整候选。按回车仍可直接提交原始字母，不改变 KOReader 的基础输入习惯。

### 个性化学习

默认开启。提交候选后，插件会在设备上记录候选偏好和个人后续词关联，并在之后的排序中使用。关闭后不读取也不新增个人排序数据，但已有数据会保留；重新开启即可继续使用。

### 后续词联想

默认开启。提交文字后，候选栏可显示静态词库、规则和个人关联生成的后续词。它与个性化学习相互独立：关闭学习但保留联想时，仍会显示静态联想，不会读取或记录个人数据。

## 为电纸书界面调整

- 紧凑候选栏只占一行，优先保留输入区域。
- 展开按钮打开多行候选面板，并提供分页操作。
- 候选点选、空格提交和虚拟键盘按键保持 KOReader 原有反馈方式。
- 更新候选时限制刷新范围；展开、收起和翻页时再刷新对应区域。
- 长文本末尾输入只排版当前可见尾部，不再随全文长度增加每键开销。
- 输入框最终关闭时立即释放引擎、候选背景和延迟任务，避免长时使用后累积占用。
- 个人学习数据使用单一低优先级写入器延迟落盘，按键处理不再同步序列化大量学习数据。

## 安装

1. 下载 [pinyinime.koplugin-v1.1.1.zip](https://github.com/Merpyzf/pinyinime.koplugin/releases/download/v1.1.1/pinyinime.koplugin-v1.1.1.zip)。
2. 解压压缩包，得到顶层文件夹 `pinyinime.koplugin/`。
3. 用 USB 将阅读器连接到电脑，把整个文件夹复制到 `koreader/plugins/`。
4. 确认最终路径为 `koreader/plugins/pinyinime.koplugin/main.lua`，不要多套一层同名目录。
5. 安全弹出阅读器，然后重启 KOReader。
6. 在 KOReader 中启用“简体中文”键盘布局。
7. 进入 `设置 → 设备 → 键盘 → 拼音输入法`，确认菜单中显示 `版本：v1.1.1`。

发布包解压后约占 160 MiB。考虑复制过程和后续升级，建议设备至少预留 200 MiB 可用空间；精确大小和校验值见 [v1.1.1 版本记录](versions/v1.1.1.md)。

## 升级

1. 退出 KOReader。
2. 下载并解压新版本。
3. 用新的 `pinyinime.koplugin/` 完整替换 `koreader/plugins/` 中的旧插件目录，不要在旧目录上合并零散文件。
4. 安全弹出设备并重新启动 KOReader。
5. 在插件设置底部核对版本，并打开“运行状态与诊断”确认词库状态。

个性化设置保存在插件目录之外，正常覆盖插件不会删除学习数据。

## 卸载

1. 退出 KOReader。
2. 删除 `koreader/plugins/pinyinime.koplugin/`。
3. 重新启动 KOReader。

卸载后，简体中文键盘及其设置菜单恢复为 KOReader 原有行为。个人设置文件默认保留，便于再次安装；如需彻底删除，可在卸载前先使用“清除个性化数据”。

## 日常使用

| 操作 | 结果 |
| --- | --- |
| 输入拼音 | 更新紧凑候选栏与行内预编辑 |
| 按空格 | 提交第一个候选 |
| 点候选 | 提交指定候选 |
| 点候选栏右侧箭头 | 展开或收起多行候选面板 |
| 在展开面板点左右箭头 | 切换候选页 |
| 按退格 | 逐步删除尚未提交的拼音 |
| 按回车 | 提交原始字母 |
| 长按空格 | 快速选择全拼或双拼方案 |
| 切换到英文键盘 | 暂停拼音接管，使用 KOReader 原始英文输入 |

## 设置

入口：`设置 → 设备 → 键盘 → 拼音输入法`

| 设置 | 用途 | 适用场景 |
| --- | --- | --- |
| 输入方案 | 选择全拼或五种双拼；当前方案显示在菜单标题中 | 日常切换输入习惯；也可长按空格快速选择 |
| 个性化学习 | 控制个人候选排序、个人后续词关联和会话学习 | 公用设备、临时输入或希望固定词库排序时可关闭 |
| 后续词联想 | 控制提交后的后续词候选 | 连续输入短句时开启；希望提交后立即清空候选栏时关闭 |
| 高级设置 → 词库模式 | “自动”使用完整万象词库并在异常时回退；“兼容词库”直接使用轻量词库 | 排查数据库或设备兼容问题 |
| 运行状态与诊断 | 显示运行状态、兼容性验证、输入方案、实际词库模式和两个功能开关 | 安装核对、升级验证和故障反馈 |
| 清除个性化数据 | 永久删除候选排序、个人后续词关联和当前会话学习数据 | 设备转交、重新训练或排查异常排序 |
| 版本 | 显示当前插件版本 | 核对升级结果和提交故障报告 |

两个开关会立即生效，不会提交或清除正在输入的拼音。关闭个性化学习只停用数据，关闭期间仍可清除已有数据。

## 兼容范围

- 最低支持：KOReader `v2025.10`。
- 正式验证：KOReader `v2025.10`、`v2026.03`、`v2026.07`。
- 更高版本：启动时进行运行时能力检测；检测通过后启用增强层。
- 键盘：仅接管 KOReader 简体中文虚拟键盘。
- 设备：面向可运行上述 KOReader 版本、并有足够存储空间的 Kindle 与其他电纸书设备。

遇到不受支持的接口或运行时错误时，插件会停用本次会话的增强层并恢复 KOReader 原始输入，以避免影响其他输入框。

## 数据位置

个人设置与学习数据保存在 KOReader 设置目录中的：

```text
koreader/settings/chinesepinyin.lua
```

该文件可能包含你的输入偏好和个人词语关联。备份时可保留它；提交故障报告时请不要上传它。发布词库位于插件目录的 `data/` 下，为只读数据。

## 常见问题

### 看不到“拼音输入法”菜单

先确认插件已在 KOReader 插件管理中启用，再确认键盘布局包含“简体中文”。重启 KOReader 后，入口应位于 `设置 → 设备 → 键盘`。

### “实际词库模式”显示兼容词库

插件在完整数据库打不开、校验不通过或 SQLite 能力不满足时会自动回退。请重新复制完整发布包，确认 `data/wanxiang.sqlite3` 和 `data/academic_supplement.sqlite3` 均存在，并查看“运行状态与诊断”的技术详情。

### 关闭个性化学习会删除记录吗

不会。关闭只会停用读取和写入；重新开启后旧排序继续生效。只有“清除个性化数据”会永久删除相关记录。

### 为什么关闭学习后仍有后续词

后续词联想是独立设置。只要联想开启，静态词库和规则生成的候选仍会显示，但不会使用或记录个人关联。

### 如何确认下载文件完整

下载同一 Release 中的 `SHA256SUMS.txt`，计算压缩包的 SHA-256 并比对。各版本校验值也会记录在 [版本索引](versions/README.md) 中。
